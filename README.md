# Did Verstappen Win?

A no-spoilers answer to determine whether a race was worth watching.

1. Install it

   `go install github.com/rpunt/did_verstappen_win@latest`

   Ensure $(go env GOPATH)/bin is in your PATH.

2. Run the binary

   ```bash
   $ did_verstappen_win
   NO
   ```

3. ...
4. Profit
